## Стек технологий

| Слой | Технология |
|------|-----------|
| Frontend | HTML5, CSS3 (custom properties, Grid, Flexbox) |
| Backend | Node.js + Express.js |

| База данных | SQLite (better-sqlite3) |
| Авторизация | express-session + bcryptjs |
| Валидация | express-validator (сервер) + нативный JS (клиент) |
| Сессии | connect-sqlite3 |

## Установка и запуск

### Требования
- Node.js >= 18
- npm >= 9

### Шаги

```bash
# 1. Установить зависимости
npm install

# 2. Запустить сервер
npm start

# Для разработки (автоперезагрузка)
npm run dev
```

Сервер запустится на **http://localhost:3000**

При первом запуске автоматически создаётся база данных SQLite в папке `data/` и заполняется тестовыми товарами.

## Функционал

### Пользователи
- **Регистрация** — форма с валидацией (имя 3–20 симв., email, пароль мин. 6 симв. + цифра, подтверждение пароля)
- **Вход** — email + пароль, хранение сессии
- **Профиль** — данные аккаунта + история заказов
- **Выход** — уничтожение сессии

### Товары и каталог
- Список товаров с фильтрацией по категории
- Сортировка по цене (возрастание/убывание) и по названию
- Поиск по названию/описанию
- Фильтр по диапазону цены
- Страница отдельного товара с характеристиками

### Корзина
- Добавление/удаление товаров
- Изменение количества
- Хранение в сессии (работает без авторизации)
- Счётчик в шапке (обновляется через AJAX)

### Заказы
- Оформление заказа с вводом адреса и телефона
- Выбор способа оплаты
- История заказов в профиле
- Маска ввода телефона

### Отзывы
- Оценка товара (1–5 звёзд) + комментарий
- Средняя оценка на странице товара
- Один отзыв от пользователя на товар (ограничение БД)

### Обратная связь
- Форма контактов с полной валидацией
- Сохранение сообщений в БД

### UI/UX
- Тёмная/светлая тема (сохраняется в localStorage)
- Toast-уведомления при добавлении в корзину
- Анимация карточек при скролле
- Адаптивный дизайн (мобильные устройства)
- Маска ввода номера телефона
- Индикатор надёжности пароля

## Схема базы данных

- **users** — пользователи (id, username, email, password_hash, created_at)
- **products** — товары (id, name, description, price, category, condition, image, external_url, in_stock)
- **reviews** — отзывы (id, product_id, user_id, rating, comment, created_at)
- **orders** — заказы (id, user_id, total_price, delivery_address, phone, comment, status, created_at)
- **order_items** — позиции заказа (id, order_id, product_id, quantity, price)
- **contact_messages** — сообщения из формы контактов
